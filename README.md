# Teslasuit.Unity

Teslasuit.Unity is a Unity plugin that provides managed access to Teslasuit API functionality through the unity-side components and prefabs.

**If something is broken, something is missing or have any questions, please open an [Issue](https://gitlab.vrweartek.com/software/UnityPlugin/-/issues)**

At this moment, Teslasuit.Unity plugin is working on Windows Operating System only. Linux, Android and MacOS support will be added in the future releases.
Teslasuit.Unity plugin package contents:

  Folder            | Description
  ----------------- | -------------
  **Examples**      | Example scenes with a resources and scripts illustrating how to work with a plugin.
  **Libs**          | Teslasuit managed libraries (TsAPI and TsSDK) used to provide Teslasuit API functionality to the plugin.
  **Scripts**       | Components and utility scripts used by this plugin.
  **TsAssets**      | Teslasuit asset examples, such as Haptic playables and Simplified haptic channels
